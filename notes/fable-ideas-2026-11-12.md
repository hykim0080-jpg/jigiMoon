# 새 주제 후보 (Fable 5.2 서브에이전트, 2026-11-12)

발상 약 15개를 떠올리고, 그중 6개는 선행 연구를 확인했어요. 아래 4개가 남았어요. 4개 모두 완전히 새롭지는 않아요. 링크는 서브에이전트가 찾은 것이라 인용하기 전에 원문 확인이 필요해요.

## 1. 귀가 빼기를 한다: 맥놀이 소리화 → ⑭ 지구 정보 주크박스
- **문제:** 데이터를 음높이로 바꿔도 사람은 절대 음높이를 잘 구분하지 못해요. 듣기엔 예쁘지만 정보가 전달되지 않아요.
- **발상:** 평년값 소리와 실제값 소리를 동시에 들려줘요. 둘이 다르면 소리가 "우-웅" 하고 떨리는 맥놀이가 생기고, 떨림이 빠를수록 평년과 많이 다르다는 뜻이에요. 기타 줄을 맞출 때와 같은 원리예요.
- **결과물:** 지구본 아무 곳이나 누르면 40년치가 20초 소리로 나오는 웹 앱이에요. 여기에 청취 실험을 더해요. 지인 10명에게 이상값 순위를 맞히게 하고, 일반 음높이 방식과 정답률을 비교해요.
- **데이터:** NASA POWER API(MERRA-2 지점 시계열과 평년값), GISTEMP, GPM IMERG, GRACE
- **선행 연구:** 맥놀이를 정보 전달에 쓴 연구는 있어요(Ziemer 외, 내비게이션 안내). 지구 이상값에 쓴 사례는 찾지 못했어요. 새로움은 중간 정도예요.
  - https://arxiv.org/abs/1912.08609v1
  - https://icad2021.icad.org/wp-content/uploads/2021/06/ICAD_2021_20.pdf
- **위험:** 맥놀이로는 평년보다 높은지 낮은지가 구분되지 않아요. 좌우 스테레오나 음색으로 따로 표시해야 해요. 예술적인 출품작이 많은 분야라 경쟁이 치열할 수 있어요.

## 2. 지나간 자리가 곧 스펙트럼이다 → ⑫ SPHEREx
- **문제:** SPHEREx는 하늘을 훑을 때마다 같은 위치를 다른 파장으로 찍어요. 그런데 움직이는 천체는 같은 위치에 두 번 있지 않아요.
- **발상:** 사진끼리 빼지 않고, 궤도 예측 위치(JPL Horizons)를 따라가요. 지나간 자리마다 다른 파장으로 찍혔으니 궤적을 이으면 그 천체의 0.75~5 µm 스펙트럼이 돼요.
- **결과물:** 소행성 이름을 넣으면 위치를 계산하고, 사진을 오려 깜빡임 영상과 스펙트럼을 보여 주는 웹 도구예요. 세레스, 베스타 등으로 시연해요.
- **데이터:** IRSA SPHEREx 영상과 잘라내기(cutout) 서비스, JPL Horizons API
- **선행 연구:** 미션 팀이 같은 과학을 하고 있지만 목록은 아직 공개 전이에요(EPSC 2026 초록). 움직이는 천체를 다루는 공개 도구는 없어요.
  - https://meetingorganizer.copernicus.org/EPSC2026/EPSC2026-797.html
  - https://irsa.ipac.caltech.edu/onlinehelp/spherex/spherex/sp.html
- **위험:** 어떤 사진이 그 위치를 찍었는지 찾기, 큰 파일, 천체의 자전과 거리 변화가 스펙트럼을 왜곡하는 문제가 있어요. 48시간 안에 될지는 확인 필요해요. 대회 전에 세레스로 1시간 시험해 보라는 권고가 있었어요.

## 3. 중력은 그냥 바람이다 → ⑧ 자유낙하 속 불꽃
- **문제:** 수십 년간의 연소 실험은 연료, 압력, 중력이 제각각이라 서로 비교할 수 없어요.
- **발상:** 중력 수준을 "부력이 만드는 바람 속도"로 바꿔요. 그러면 모든 실험이 산소 농도와 바람 속도를 두 축으로 한 지도 한 장 위에 올라가요. 지도에서 빈칸(달·화성 중력 구간)이 다음에 실험해야 할 우선순위가 돼요.
- **결과물:** AI가 NASA 기술 보고서에서 실험 조건과 결과를 표로 뽑고, 그 표를 지도에 찍어 "가장 덜 실험됐고 가장 위험한 구간" 순위를 보여 줘요.
- **데이터:** NASA Technical Reports Server, NASA Physical Sciences Informatics(AWS 공개 데이터)
  - https://registry.opendata.aws/nasa-psi
- **선행 연구:** 물리 원리는 이미 알려져 있어요. 전체 기록을 이렇게 정리한 도구는 찾지 못했어요.
- **위험:** 데이터 추출이 지저분하고, 연료·두께가 다르면 비교가 근사치에 그쳐요.

## 4. 자연에는 주말이 없다 → ② 추세 탐정
- **문제:** 대기 변수의 추세만 보고는 사람 때문인지 날씨 때문인지 알 수 없어요.
- **발상:** 자연에는 7일 주기가 없으니, 7일 주기 신호의 크기는 순수하게 사람이 만든 신호예요.
- **선행 연구:** 많이 나와 있어요(Beirle 2003, Stavrakou 2020). 새로움은 낮아요.
  - https://acp.copernicus.org/articles/3/2225/2003/
